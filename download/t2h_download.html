Windows users:

For Internet Explorer:
         *  Right click on the above links and select Save Target As to save the font in some directory of your choice.
         *  Click the Start button and from the Settings option select Control Panel.
         *  A window will pop up and double click the Fonts icon in it.
         *  Now select the Install New Fonts option from the File menu.
         *  Select the downloaded font file you have saved in the previous step and click the Install button.

For Netscape Navigator:
         *  Right click on the above links and select Save Link As to save the font in some directory of your choice.
         *  Click the Start button and from the Settings option select Control Panel.
         *  A window will pop up and double click the Fonts icon in it.
         *  Now select the Install New Fonts option from the File menu.
         *  Select the downloaded font file you have saved in the previous step and click the Install button.
