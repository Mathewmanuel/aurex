Font Download

Windows users:

For Internet Explorer:
         *  Right click on Tabanna or Tabmaduram and DV-TTYogesh and select Save Target As to save the font in some directory of your choice.
         *  Click the Start button and from the Settings option select Control Panel.
         *  A window will pop up and double click the Fonts icon in it.
         *  Now select the Install New Fonts option from the File menu.
         *  Select the downloaded font file you have saved in the previous step and click the Install button.

For Netscape Navigator:
         *  Right click on Tabanna or Tabmaduram and DV-TTYogesh and select Save Link As to save the font in some directory of your choice.
         *  Click the Start button and from the Settings option select Control Panel.
         *  A window will pop up and double click the Fonts icon in it.
         *  Now select the Install New Fonts option from the File menu.
         *  Select the downloaded font file you have saved in the previous step and click the Install button.


Linux users:

         *  Download the Tabakaram font.

         Font Installation
             *  After downloading the tabakaram.tar.gz file, type following commands from command prompt
                     $ tar -zxvf tabakaram.tar.gz

             *  This will create a directory named 'fonts' in the current directory. Now,
                     $ cd fonts/
                     $ mkfontdir

             *  This will create a "fonts.dir" file in the fonts/ directory.
                     $ xset +fp (path of the fonts.dir file without any brackets)
                     $ xset fp rehash

         Effecting changes in the browser
             *  Now, enable the font changes in the browser. In mozilla, this can be found in: Edit > Preferences > Appearance > Fonts.
             *  Change to 'User Defined' in the Fonts for menu.
             *  Change the 'Serif' & 'Sans_Serif' fonts to 'tabakaram' and reload the page.
