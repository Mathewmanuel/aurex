					Tamil WordNet

					README

Developed by: AU-KBC Research Centre, Chennai (http://www.au-kbc.org)
With partial funding from: Tamil Virtual University, Chennai (http://www.tamilvu.org)

This README is to serve as a guide for the contents of this CD/ directory containing the details about Tamil WordNet.

Credits:

The Tamil WordNet has been based on the Tamil Thesaurus developed by Dr. S Rajendran, Tamil University, Thanjavur. He is also instrumental in designing the framework for the Tamil WordNet. He has taken painful and arduous efforts in collecting lexicographic and linguistic details.
